# Bosh Civils Website

A modern, responsive static website for **Bosh Civils (PTY) Ltd**, designed for free hosting on GitHub Pages.

## Before publishing

1. Replace the placeholder contact details in the Contact section with verified Bosh Civils information.
2. Replace the demo Facebook link if the supplied link is not the actual Bosh Civils page.
3. Add real project images once available.
4. Connect the enquiry form to a static-site form provider such as Formspree or Basin if submissions are required.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `bosh-civils`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Commit and push the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder.
7. Save. GitHub will provide the live URL after deployment completes.

## Custom domain

Once the GitHub Pages URL works, a custom domain can be configured under **Settings → Pages → Custom domain** and the relevant DNS records can then be added at the domain provider.
